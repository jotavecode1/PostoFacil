# Easy Money - Sistema de Caixa

Desenvolvido por **Aurion Solutions**.

## Descrição
Sistema de cálculo de troco para postos de gasolina, com interface visual para facilitar a identificação de notas e moedas.

## Funcionalidades
- **Login Seguro**: Acesso restrito a operadores (Usuário: `joao`, Senha: `1`).
- **Cálculo Automático**: Insira o valor a cobrar e o valor pago.
- **Visualização de Troco**: Mostra exatamente quais notas e moedas devolver.
- **Histórico**: Registro das últimas transações na barra lateral.

## Como Usar
1. Abra o arquivo `index.html` no seu navegador.
2. Faça login com as credenciais padrão.
3. Comece a operar o caixa.

## Tecnologias
- HTML5
- CSS3 (Design Moderno e Responsivo)
- JavaScript (Lógica de Cálculo)
